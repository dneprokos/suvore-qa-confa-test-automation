# MCP + skill — publish test cases to Confluence

## Page mode — one section on an existing page

```text
Publish the test cases from docs/use-cases/2_1_build-skill/sample-output.md to Confluence page <PAGE_URL>.

```

## Sub-page mode — the story's own page under a parent

```text

Story title: Owner adds a new admin. Ticket: SCRUM-139.
```
