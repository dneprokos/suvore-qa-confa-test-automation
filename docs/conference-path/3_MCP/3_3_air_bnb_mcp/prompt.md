# Airbnb MCP — cheapest stays in Prague

```text
Find the 10 cheapest Airbnb stays in Prague for Fri Oct 2 – Sun Oct 4 (2 nights), 1 adult.

Filters:
  - Private room or entire place only, no shared dorms
  - Within Prague city limits, ideally near public transport or within ~30 min of the Old Town
  - Rating 4.5+ with at least 10 reviews (new listings OK if clearly marked)

Output:
  - Total price in PLN, including fees
  - A table with name + link, total price, rating, area and a one-line note, sorted cheapest first
  - End with your top pick for value
```
